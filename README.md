# Portfólio - Página de "Link na Bio"

Projeto do curso de Análise e Desenvolvimento de Sistemas (Faculdade Flamingo), focado em HTML5 semântico e CSS3 moderno.

## 🚀 Sobre o Projeto

Página de links centralizada, no estilo Linktree, que funciona como portfólio inicial e cartão de visitas digital. É responsiva e segue boas práticas de acessibilidade e organização de código.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** tags semânticas (`<main>`, `<header>`, `<section>`, `<footer>`).
- **CSS3:** Flexbox, variáveis CSS (Custom Properties) e design responsivo.
- **Acessibilidade:** atributos `alt`/`aria-label` e classe `sr-only` para leitores de tela.

## 💻 Como Executar

1. Clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Não há dependências para instalar.
